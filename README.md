# Learning — Что я изучаю

Это репозиторий для хранения материалов обучения и портфолио.

Структура репозитория направлена на два сценария:
- Место для изучения: заметки, конспекты, материалы курсов.
- Портфолио: каталог проектов и готовых работ, которые можно показать.

Дальше в репозитории есть каталоги с подсказками, как заполнять и где хранить PDF/текстовые материалы и эссе.
