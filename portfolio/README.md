# Портфолио

Папка `portfolio/` содержит каталог проектов и шаблоны для оформления каждой работы, чтобы удобно показывать результаты.

Структура:
- `catalog.md` — главный каталог с индексом проектов
- `projects/<project-name>/` — папка с конкретным проектом: описание, скриншоты, исходники, ссылка на демо
- `template_project.md` — шаблон для добавления новых проектов в каталог

Добавляй проекты в `portfolio/projects/` и обновляй `catalog.md`.
