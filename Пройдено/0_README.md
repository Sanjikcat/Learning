# Learned Materials / Изученные материалы

В этой папке лежат курсы, материалы, книги и полная информация по конспектам и тому что я изучал

Структура:
- `Лист курсов` - Краткий списко пройденных курсов, составлять по форме - `Год_Курс_Платформа_Название`)
- `TXT` - Это текстовый формат где есть мои конспекты, зачастую это конспект книг
- `Важные` - Это тэг для кратких но информативных вещей из материалов
