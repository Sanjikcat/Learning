# Completed Courses / Пройденные курсы

В эту папку складывай копии сертификатов, PDF-материалов и текстовые файлы с пройденными курсами.

Структура:
- `pdfs/` — PDF сертификаты и книги (переименовывай файлы по шаблону: `Год_Курс_Платформа_Название.pdf`)
- `txt/` — текстовые версии конспектов или списки пройденных курсов
- `courses_list.txt` — машинно-читаемый список пройденных курсов (пример ниже)

Важно: если в файлах есть персональные данные, подумай о приватности — репозиторий приватный.
