# Эссе и рефлексии

Папка `essays/` для эссе, рефлексий и итоговых заметок по курсам и проектам.

Как пользоваться:
- Каждый документ — отдельный файл `YYYY-MM-DD_название.md`.
- В начале файла указывай курс/проект и ключевые выводы.
- В конце — список источников и дальнейшие шаги по изучению.
