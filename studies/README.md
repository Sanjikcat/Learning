# Структура для учебы

Папка `studies/` предназначена для текущих и будущих курсов, заметок и практики.

Рекомендуемая структура внутри `studies/`:
- `courses/<название_курса>/` — заметки и домашние задания по конкретному курсу
  - `notes.md` — конспект
  - `assignments/` — решения заданий
  - `resources/` — ссылки, книги, статьи
- `practice/` — небольшие упражнения и лабораторные
- `templates/` — шаблоны заметок и отчётов

Пример: `studies/courses/python-basics/notes.md`.
